# 基本的な型と関数

Effectはこのような型で表されます．

```ts
Effect<A, E, R>
```

## 成功値と失敗値を生成する

成功したことを表す`Effect`を生成するには`Effect.succeed`を使います．

```ts twoslash
import { Effect } from 'effect';
// ---cut---
const succeed = Effect.succeed(42);
```

反対に，失敗したことを表す`Effect`を生成するには`Effect.fail`を使います．

```ts twoslash
import { Effect } from 'effect';
// ---cut---
// fail!
const fail = Effect.fail('fail!!!');
```

## 同期関数・非同期関数から`Effect`を生成する
`throw`しないことが分かっている同期関数を実行し，`Effect`を生成する場合は`Effect.sync`を使います．

```ts twoslash
import { Effect } from 'effect';
// ---cut---
const sync = Effect.sync(() => Date.now())
```

非同期関数であれば`Effect.promise`を使います．
```ts twoslash
import { Effect } from 'effect';
// ---cut---
const promise = Effect.promise(() => fetch('https://'))
```

これらの関数には`throw`しないことが分かっている関数のみを渡すことになっているので，`throw`してしまった場合は`Effect`内部で予期しないエラー(`thunk`)として処理されます．

throwするかもしれない関数のエラーハンドリングを行いたい場合は，同期・非同期関数それぞれに`Effect.try`, `Effect.tryPromise`という関数が用意されています．

```ts twoslash
import { Effect } from 'effect';
// ---cut---
const tryEffect = Effect.try({
  //  ^?
  try: () => JSON.parse("invalid json"),
  catch: (error) => `Failed to parse JSON: ${String(error)}`,
});
```

Effect.syncとEffect.succeedは一見すると同じことをしているように見えます．しかし，Effectに包んでからの処理が少し違います．
試しにDate.now()をそれぞれで包んでみましょう．一度だけの実行では違いはありませんが，複数回実行したときに差が生まれます．
Effect.succeedは生成した時点での値を保持します．つまり，複数回同じEffectを実行しても最初の実行で格納された同じDateが毎回返ってきます．
それに対してEffect.syncは実行のたびに渡された同期関数を実行します．そのため，実行ごとに値が異なります．
